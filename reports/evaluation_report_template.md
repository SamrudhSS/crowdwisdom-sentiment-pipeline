## Methodology notes

- **Model**: one independent LightGBM gradient-boosted tree regressor per
  horizon (`src/models/train.py`), trained on price- and sentiment-only
  features (`src/features/feature_engineering.py`).
- **Validation**: 5-fold expanding-window walk-forward split. Train window
  grows each fold; test window is a fixed forward slice immediately after
  the train window. No shuffling, no k-fold CV (would leak future into
  past), no test-set reuse across folds.
- **Strategy construction** (for Sharpe/Sortino/MaxDD only): long the asset
  from bar t to bar t+h when the model's predicted price at t+h exceeds the
  close at t, otherwise flat. This is a simple, fully mechanical rule used
  only to translate price forecasts into a return series for risk-adjusted
  performance scoring — it is not a proposed trading system.
- **Annualization**: Sharpe/Sortino scaled by sqrt(bars/year) for the
  configured bar size (1-hour bars → sqrt(24×252); daily bars → sqrt(252)).

## Limitations
- Sentiment is scored with VADER (lexicon-based); it is fast and needs no
  extra model download, but is weaker than a fine-tuned transformer on
  sarcasm/financial jargon. Swappable in `src/features/sentiment_scoring.py`.
- 180 days of hourly bars is a modest sample for 5 walk-forward folds;
  results should be read as a methodology demonstration, not a production
  alpha claim.
- X post coverage depends entirely on what the chosen Apify actor returns
  for the search terms used — see `reports/run_manifest.json` for the exact
  actor ID and search terms used on this run.
